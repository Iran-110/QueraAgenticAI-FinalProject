# نمای خواندنی برای ارائه

`presentation_view.py` یک صفحهٔ اختیاری و جدا از UI اپراتور است. برای جلسه،
داور می‌تواند وضعیت پرونده، نسخهٔ فعلی کاربر، گفت‌وگو، پیشنهاد و منابع را
راحت‌تر ببیند. متن کامل پاسخ و handoff بدون تغییر داخل بخش‌های بازشدنی می‌ماند.
عنوان‌های کوتاه، نمایش وضعیت رابط‌اند؛ پاسخ مدل را بازنویسی نمی‌کنند.

این نما فقط `GET /health` و `GET /cases/{case_id}` را برای فهرست مشخص‌شده
می‌فرستد. مسیر نوشتن، پیام تازه، review، funding و model call ندارد. token
reviewer و کلید API خوانده یا به مرورگر داده نمی‌شوند؛ برای گفت‌وگو، correction
و approval از UI اصلی استفاده کنید. به‌روزرسانی دستی است و polling خودکار نداریم.

## اجرا

پس از راه‌اندازی backend، فقط دو تنظیم عمومی همان جلسه لازم است:

```bash
AGENT_API_URL=http://127.0.0.1:8001 \
AGENT_PRESENTATION_CASES='["CASE_ID_FROM_THE_APPROVED_PROTOCOL"]' \
uv run streamlit run presentation_view.py --server.address 127.0.0.1 --server.port 8503 --server.headless true --browser.gatherUsageStats false
```

نام‌های واقعی را از protocol مصوب بردارید. این فرمان scope تازه نمی‌سازد و
ظرفیت جلسه را مصرف نمی‌کند. فایل entrypoint جزو navigation پیش‌فرض نیست.

در نمای API، برچسب live فقط تنظیم backend را توضیح می‌دهد؛ رسید provider
شاهد اجرای واقعی درخواست است. اگر gateway ضبط‌شدهٔ QA با
`display_origin="recorded_rehearsal"` استفاده شود، بالای صفحه صریحاً نوشته
می‌شود «پروندهٔ ثبت‌شده در اجرای پذیرش؛ اجرای تازهٔ مدل نیست».

پیشنهاد منتظر بررسی و سابقهٔ پیام تأییدشده جدا نمایش داده می‌شوند. پاسخ تأییدشده
به معنی حل مسئله نیست. نسخه و منابع سابقهٔ تأیید از همان handoff تاریخی می‌آیند
و به وضعیت تازهٔ پرونده نسبت داده نمی‌شوند. برچسب قدیمی `synthetic` به‌عنوان
اثبات نوع provider استفاده نمی‌شود؛ مقدار اصلی در بخش فنی قابل مشاهده است.

## مرز و شواهد

- body نامعتبر، پروندهٔ دیگر، متن draft تغییرکرده یا reference/handoff دستکاری‌شده
  پیش از نمایش رد می‌شود؛ اعتبارسنج موجود `BackendClient` حفظ شده است.
- transport دوم نیز method، path و نبود header/body اضافی را کنترل می‌کند.
  نشانی فقط HTTP محلی با port مشخص است؛ credential URL، proxy محیط و redirect نداریم.
- متن کاربر، متن منبع و متن پاسخ به‌صورت plain text نمایش داده می‌شوند؛ Markdown
  ورودی نمی‌تواند تصویر بیرونی یا HTML بارگذاری کند. پیش‌نمایش منبع صریحاً فقط
  ۱۸۰ نویسهٔ نخست آن است و متن کامل کنار آن قابل بازشدن است. لینک منبع فقط پس از
  بررسی HTTP(S)، نبود credential و نبود نویسهٔ کنترلی فعال می‌شود؛ در غیر این
  صورت نشانی فقط متن است. client خواندنی با `on_release` موجود در Streamlit
  پس از آزادشدن cache نشست بسته می‌شود.
- چیدمان دو ستونهٔ عریض و چیدمان عمودی در عرض ۳۹۰ پیکسل با CUA/Safari و
  پرونده‌های ضبط‌شدهٔ پذیرش بررسی شده‌اند. این بررسی، آزمون کیفیت مدل نیست.

این لایهٔ نمایش بیرون binding مالی ۲۱ فایل backend است؛ inventory مستقل
فایل‌های آن در بستهٔ محلی ارائه ثبت می‌شود. هیچ منطق core، renderer پاسخ،
متن تأییدشده، protocol، ledger یا halt برای این نما تغییر نمی‌کند.

آزمون متمرکز:

```bash
uv run pytest -q tests/test_presentation_view.py
```
