# ارائهٔ محصول برای داورها

[PDF فارسی ۱۳ اسلایدی](judges-presentation-fa-v2.pdf) برای screen share و
[نسخهٔ HTML مستقل](judges-presentation-fa-v2.html) برای ویرایش/نمایش آماده‌اند.
HTML فونت و تصویرها را در خود دارد؛ بازکردن آن به اینترنت نیاز ندارد. کلید F
حالت نمایش را فعال می‌کند؛ جهت‌ها و PageUp/PageDown صفحه را عوض می‌کنند و
Escape از حالت نمایش خارج می‌شود.

روایت برای مخاطب غیرتخصصی است: مسئله، محصول، منابع، نحوهٔ رسیدگی، کنترل انسان،
شواهد اجرا، محدودیت کیفیت و سهم اعضا. آخرین صفحه برای ورود به دموی محصول است.
متن ورودی آزمایش، دستور اجرا، سؤال‌های احتمالی داور و یادداشت خصوصی ارائه‌دهنده
در این فایل‌های عمومی نیستند.

عدد ۱۲۶۷ تست در اسلاید ۱۰ مربوط به پذیرش تاریخی C4v روی source `cf5fa50` است؛
نتایج تازهٔ software در [رسید C4w](../receipts/presentation-readiness-2026-10-18.json)
جدا ثبت می‌شوند. هفت نوبت/هشت درخواست واقعی، پذیرش محدود عملیاتی بوده‌اند؛
اسلایدها ادعای حل Enum یا تکمیل held-out نهایی ندارند. تصاویر پرونده‌ها ضبط‌شدهٔ
همان پذیرش‌اند و به‌عنوان اجرای تازهٔ مدل معرفی نمی‌شوند.

برای راه‌اندازی و حدهای جلسه، [راهنمای C4w](../presentation-readiness.fa.md) و
[مسیر live محدود](../presentation-live.fa.md) مرجع‌اند. bootstrap عادی در حالت
halt مجاز به ارسال نیست؛ ساخت نسخهٔ تازهٔ مجوز یا reset ledger دستور دمو نیست.

PDF و HTML byte-for-byte با نسخهٔ بازبینی‌شدهٔ بستهٔ محلی یکسان‌اند. هر ۱۳ صفحهٔ
PDF واقعی render و بصری بررسی شده‌اند؛ ویرایش بعدی نیاز به render/review تازه
و ثبت hash جدید دارد. راهنمای گفتار، Q&A و مرجع سریع چت در بستهٔ خصوصی ساسان
باقی می‌مانند.
