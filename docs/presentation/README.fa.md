# ارائهٔ محصول برای داورها — نسخهٔ ۳

برای ارائه، [PDF فارسی ۱۵ اسلایدی](judges-presentation-fa-v3.pdf) را باز کنید.
[HTML مستقل و قابل ویرایش](judges-presentation-fa-v3.html) همان محتوا را با فونت
و تصویرهای تعبیه‌شده دارد. کلید F حالت ارائه را باز می‌کند؛ PageDown و PageUp
اسلاید را عوض می‌کنند و Escape به نمای عادی برمی‌گردد.

[راهنمای اسلایدبه‌اسلاید ارائه‌دهنده](speaker-notes-fa-v3.md) جداست: متن طبیعی
گفتن، زمان، محل اشاره و جملهٔ انتقال. مسیر پیشنهادی ۲۹ دقیقه، شامل ۶ دقیقه
نمایش محصول است. نسخهٔ خواندنی خصوصی با دکمهٔ اسلاید قبل/بعد و حالت «فقط متن
گفتن»، همراه مرجع فنی، در بستهٔ محلی ساسان قرار دارد.

## روایت

مسئله و ارزش محصول، محیط گفتگو و ثبت اطلاعات، معماری چهار بخش، منابع و آماده‌سازی
داده، retrieval متناسب با نسخه، تصمیم agent، correction و بررسی انسان. پس از
نمایش محصول، روش ارزیابی، نتایج مسیر متصل و مسئولیت اعضا جمع می‌شوند.

تصویر رابط از محیط واقعی گرفته شده است. نشانگر ۱ محل پیام، ۲ وضعیت پرونده و ۳
فرم اطلاعات را معرفی می‌کنند؛ Name و Value با ترتیب واقعی و توضیح فارسی جدا
نمایش داده می‌شوند. کد نسخه‌ها و اصطلاحات انگلیسی جهت مستقل دارند.

PDF اصلی دستور اجرا، prompt آزمایش، سؤال احتمالی داور یا توضیح‌های داخلی مالی
ندارد. تعداد منابع، تعداد پرونده‌های ارزیابی و پذیرش تاریخی ۷ نوبت/۸ درخواست
هر کدام با دامنهٔ خودشان بیان می‌شوند. اجرای نهایی مستقل هنوز کامل اعلام نشده
و حل Enum یا افزایش اندازه‌گیری‌شدهٔ کیفیت پاسخ ادعا نمی‌شود.

[منابع هر اسلاید و provenance تصویرها](judges-v3-source-map.json) و
[رسید بررسی محتوا، PDF، RTL/LTR و راهنمای گفتاری](judges-v3-qa.json) همراه فایل‌هاست.
هر ۱۵ صفحهٔ PDF واقعی با Poppler رندر و بصری بررسی شده‌اند؛ فونت‌های متن تعبیه
شده‌اند. HTML و راهنما برای باز شدن به منبع اینترنتی وابسته نیستند.

## ارتباط با اجرای جلسه

این تحویل، محتوای ارائه را عوض می‌کند؛ backend، protocol مالی، halt، build و
watch اجرایی جلسه ثابت‌اند. [راهنمای اجرای پذیرفته‌شده](../presentation-readiness.fa.md)
همچنان مرجع کنترل سرویس‌ها و ظرفیت است. healthcheck موجود برای artifactهای v2
ثبت شده؛ رسید v3 مستقل است و نتیجهٔ آن به نام v2 ثبت نمی‌شود.

[PDF قبلی v2](judges-presentation-fa-v2.pdf)، [HTML قبلی](judges-presentation-fa-v2.html)
و [راهنمای همان نسخه](README-v2-archive.fa.md) حفظ شده‌اند. برای نمایش جدید، فایل v3
را انتخاب کنید؛ بازنویسی فایل‌های قبلی یا تغییر تنظیم مدل برای استفاده از آن لازم نیست.
